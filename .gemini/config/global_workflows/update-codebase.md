<role>
Update codebase map with verified, newly discovered knowledge.
Use when: traced flows, discovered patterns, resolved questions, new domains/infra slices.
</role>

<objective>
Incrementally update the split codebase knowledge base with verified facts.
Flow: Recall → Verify → Target → Update
</objective>

<context>
Codebase Map files:
- `./.gtd/CODEBASE.md`
- `./.gtd/codebase/architecture.md`
- `./.gtd/codebase/entrypoints.md`
- `./.gtd/codebase/patterns.md`
- `./.gtd/codebase/open-questions.md`
- `./.gtd/codebase/domains/index.md`
- `./.gtd/codebase/domains/*.md`
- `./.gtd/codebase/infra/index.md`
- `./.gtd/codebase/infra/*.md`
</context>

<prohibitions>
- **No Guessing:** Document only verified facts.
- **Evidence Inline:** Cite changed claims via `Evidence: path:line`.
- **Admit Gaps:** Log questions in `open-questions.md`.
- **Minimal Edits:** Do not rewrite everything. Update smallest correct file set. Do not dump details into `CODEBASE.md`.
</prohibitions>

<process>

## 1. Identify What You Learned
Format findings:
```text
LEARNED:
- [What changed] — [Evidence: file:line]
```

## 2. Map Findings To Target Files
| Knowledge Type | Target File |
| -------------- | ----------- |
| Subsystem/Structure | `architecture.md` |
| Startup flows | `entrypoints.md` |
| Conventions | `patterns.md` |
| Unresolved gaps/questions | `open-questions.md` |
| Domain behavior | `domains/<name>.md` |
| Infrastructure | `infra/<name>.md` |
| New slice | Create slice, update `index.md` |

Update `CODEBASE.md` index only if files added, renamed, or global purpose changed.

## 3. Update Target Files
Verify file exists, update section, add inline evidence, refresh `Last Updated` and `Last Verified`. Delete stale contradictory text.

## 4. File-Specific Rules
- `CODEBASE.md`: short index only.
- `architecture.md`: subsystems concise, end with evidence.
- `entrypoints.md`: verified flows with evidence.
- `patterns.md`: documented patterns in ≥2 files, ≥2 evidence citations.
- `open-questions.md`: remove solved, add new, concrete next steps.
- `domains/*.md` & `infra/*.md`: narrow scopes, flows/tables.
- `domains/index.md` & `infra/index.md`: auto-generated by `./.gtd/scripts/generate-index.sh`. Do not manually edit. Recreate script if missing:
  1. Accepts target directory as arg.
  2. Overwrites `index.md` in directory.
  3. Imports full contents of every `.md` (except `index.md` itself) with comment headers/footers.

## 5. Finalize Indexes
```bash
bash ./.gtd/scripts/generate-index.sh ./.gtd/codebase/domains
bash ./.gtd/scripts/generate-index.sh ./.gtd/codebase/infra
```

</process>

<output_format>

```text
---
  GTD ► CODEBASE DOCS UPDATED ✓
---

| File | Change |
|------|--------|
| {path} | {what changed} |

---
```

</output_format>

<forced_stop>
STOP. The workflow is complete. Do NOT automatically run the next command. Wait for the user.
</forced_stop>
