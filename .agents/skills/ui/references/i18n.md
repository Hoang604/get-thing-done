# Internationalization (i18n), Locale Formatting, and Bidirectional (RTL) Layout

## Logical Layout and Directional Icon Mirroring

- **When** writing direction-dependent CSS and rendering icons under bidirectional (`ltr`/`rtl`) support, use CSS logical properties (`margin-inline-start`, `padding-inline-end`, `inset-inline-start`, `border-inline-end`, `border-start-start-radius`, `text-align: start`) instead of physical `left`/`right` (using physical `left`/`right` only when paired with physical `env(safe-area-inset-left/right)` plus a `[dir="rtl"]` override, and adding explicit `[dir="rtl"]` overrides for `translateX` and `background-position`), mirror progression sequences (steppers, progress bars, rating meters) so they advance from the inline start edge, and under `[dir="rtl"]` flip (`scale: -1 1`) only icon glyphs or composite icon sub-parts that depict reading flow or navigation direction while keeping badges/slashes in place. *Guardrail*: Never flip brand logos, checkmarks, media transport controls, clockwise time icons, or icons depicting asymmetric physical objects in RTL, and never apply two flip transforms to the same icon.
- **When** sizing controls and horizontal bars for translated copy, set `max-width: 100%` on buttons/labels and `flex-wrap: wrap` on control rows so containers absorb `30–40%` text expansion without horizontal clipping or forced single-word truncation. *Guardrail*: Never set a fixed inline `width` on text buttons or translated labels.

## Translatable Messages, `Intl` Formatting, and Bidirectional Text Isolation

- **When** authoring translatable strings, formatting locale-sensitive values, or rendering user-supplied text in multi-locale interfaces, author each message as a complete sentence with named placeholders using ICU MessageFormat or `Intl.PluralRules(locale)`, format all dates, numbers, currencies, units, relative times, and conjunction lists through `Intl.DateTimeFormat`, `Intl.NumberFormat`, `Intl.RelativeTimeFormat`, and `Intl.ListFormat` with the user's locale (including locale-aware digits and calendars where applicable, derived from user preference or `Accept-Language` / `navigator.languages`), set accurate `lang` and `dir` attributes (allowing paragraphs of three or more lines to align to their own script's direction), wrap mixed-direction user values (names, codes, URLs, numbers) in `<bdi>`, mark brand names, code tokens, and identifiers with `translate="no"`, and preserve Zero-Width Non-Joiner (`U+200C` in Persian/Kurdish) while treating Arabic/Persian Yeh (`ي`/`ی`) and Kaf (`ك`/`ک`) variants as equivalent in search and validation. *Guardrail*: Never build sentences by string concatenation (`"You have " + n + " items"`), never hardcode binary English plurals (`n === 1 ? "" : "s"`) or manual `", "`/`" and "` list joins, never reorder digits manually, and never infer display language from IP address instead of `Accept-Language` / `navigator.languages`.
